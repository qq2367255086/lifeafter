# 明日之后 · 角色数据记录器

多账号台账工具。自动识别你在本机登录过的游戏角色，按天记录金条、周积分等数据，并生成趋势图表，帮你管好手上的一堆号。

> **安全声明：不修改游戏文件、不注入进程、不读取游戏内存。**
> 它只做两件事：读游戏目录里本来就有的文本文件、给游戏窗口"拍照"做文字识别（OCR）。

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| 自动找号 | 扫描游戏窗口和本地录像记录，列出所有登录过的角色，一键导入 |
| 按天记录 | 金条、周积分、庄园等级、金核心任务/期数等，每天记一笔 |
| 一键识别 | 每个号打开同一个界面，点一下按钮，全部号的数值自动识别填好 |
| 趋势图表 | 每个字段都有合计趋势图，赚了还是亏了一目了然 |
| 导出 CSV | 随时导出成表格文件，用 Excel 自己再加工 |
| 成本计算 | 配套「明日小助手」小程序/App，算制作成本和利润（见第六章） |

## 二、下载安装

1. 打开下载页面：**https://github.com/qq2367255086/lifeafter/releases/latest**
2. 下载最新版的 `明日之后角色记录器-vX.X.X.exe`（就一个文件）
3. 放到你喜欢的文件夹（比如 `D:\明日之后记录器\`），**双击就能用**，不需要安装
4. 程序会在自己旁边生成一个 `data` 文件夹，你的所有记录都存在里面

> 提示：Windows 10/11 直接可用；如果杀毒软件提示，选择"允许"即可（程序带完整性校验，被篡改的包会拒绝运行）。

## 三、快速上手（三步）

1. **双击打开记录器**，点右上角「**导入账号**」
   - 程序自动列出你电脑上登录过的所有角色，勾选要记录的，点「导入选中」
2. **框一次识别区域**：点顶栏「**标定识别区域**」，把任意一个号切到想记录的界面（比如背包看金条），在截图上**拖一个框**圈住那个数字，松手即保存
   - 同一分辨率下所有角色共用，**框一次以后都不用再框**
3. **开始记录**：以后每天想记账时，把各个号都打开到同一界面 → 进对应明细页点「**识别全部账号**」→ 核对一下 → 点「写入选中」，就存好了

## 四、日常使用

- **一键识别**：进「金条明细」等页面 → 右上「识别全部账号」，约 1 秒/号。识别完逐行核对，不对的行取消勾选即可
- **手动改数**：明细表格里的数值直接点击就能改，输完自动保存
- **看历史**：每行右侧「历史」按钮，可看这个号的所有记录、删单条
- **看趋势**：明细页底部是全部账号合计的趋势图，鼠标悬停看当天数值
- **加自己的字段**：左下角「添加统计字段」，想记什么就加什么（比如新资源数量），加完自动多一个明细菜单，标定一次区域就能识别

## 五、识别原理（为什么 sometimes 要你配合）

- 等级、金条这些数值**只存在服务器里**，本地拿不到，所以程序靠"截图 + 文字识别"来读数
- 识别是**按位置**读数的，所以一键识别前，**每个号必须打开到同一个界面**（比如全部打开背包）。哪个号数字明显不对，多半是它没切过去
- 换了分辨率（或改了窗口大小）需要重新标定一次区域

## 六、成本计算（明日小助手）

记录器管"记账"，**「明日小助手」管"算账"**——这是配套的手机端工具，做**制作成本与利润计算**：

- 内置游戏配方数据（武器 / 护具 / 无人机 / 半成品等分类）
- 你填一下当前市场材料价，它自动算出**一件成品的总成本**
- 对比卖价（默认按 15% 交易税扣），直接告诉你**赚不赚、赚多少**
- 材料价格随时可改，改完所有相关配方成本自动重算，多账号多配方一目了然

## 七、注意事项

1. **数据都在本地** `data` 文件夹里（`lifeafter.db` 数据库 + `exports` 导出表格），**建议定期备份这个文件夹**，删掉就等于清空所有记录
2. 一键识别时请**别把游戏窗口最小化**，保持窗口打开即可（程序会自动切窗口截图，不抢你的键盘鼠标）
3. 多开识别时如果有窗口"正在识别中"的提示浮层，等它自己消失就好，不要手动点它
4. 识别前确认游戏**分辨率一致**：所有号用同样大小的窗口，标定一次就全通用
5. 程序只在本地运行，**不联网上传你的任何数据**（仅检查更新时会访问 GitHub）
6. 游戏大版本更新后如果识别失效，属于正常情况（界面变了），等作者适配即可

## 八、常见问题

**Q：识别不出数字 / 数字不对？**
A：重新「标定识别区域」，框要紧一点、只框数字不带文字；确认所有号都打开了同一个界面。

**Q：导入账号列表是空的？**
A：先登录一次游戏（本机），让游戏生成记录文件后再导入。

**Q：程序闪退 / 报错 / 识别异常，怎么反馈？**
A：把程序目录下 `data\app.log` 文件发给作者——程序所有错误和失败明细都记录在这个文件里，拿到它就能排查。

**Q：会不会被封号？**
A：程序不注入、不读内存、不改游戏文件，只读本地文本和截屏识别，属于外部记录工具。但请自行评估使用风险。

**Q：支持手机端吗？**
A：记录器是电脑程序（配合 PC 版游戏多开使用）；成本计算有微信小程序和鸿蒙 App，手机上随时能用。
